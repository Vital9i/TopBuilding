TOP BUILDING — КЛАССИК 100
С уверенностью в будущее

В комплекте:
- classic100-tour-plan1.html ... classic100-tour-plan5.html — пять туров;
- assets/three.min.js — один общий движок Three.js r160 (MIT);
- assets/slogan.svg — рукописный слоган в векторе;
- plans/ — пять художественных визуализаций планировок в PNG.

Распакуйте архив целиком. Для просмотра откройте любой HTML в современном браузере. Не переносите HTML отдельно от папки assets. Для сайта загрузите структуру папок без изменений. Внешних CDN и шрифтов нет.

Пример вставки в вашу страницу:
<iframe src="/classic100/classic100-tour-plan5.html" title="Классик 100 — тур 5" loading="lazy" allow="fullscreen" allowfullscreen style="width:100%;height:80vh;min-height:540px;border:0"></iframe>

Для переключения туров меняйте src одного iframe. Не запускайте все пять одновременно. Loading lazy откладывает загрузку, но для запуска строго по кнопке назначайте src только после нажатия.

HTML тура 5: 35 369 байт. Общий движок: 669 884 байта. Уменьшение HTML достигнуто выносом движка, а не сокращением модели. Первая загрузка включает HTML, движок и слоган. Настройте серверное gzip/Brotli и кеширование статических файлов; фактический трафик зависит от сервера.

Визуализации переработаны по присланному референсу Classic 74: объёмная мебель, натуральное дерево, мягкие тени, таблица помещений. Исходные схемы получены из пяти туров. Расположение комнат взято из моделей; художественные визуализации не являются точными обмерными чертежами. Авторитетный источник геометрии — 3D-туры. Для всех комнат подписи в комплекте рассчитаны из прямоугольников пола модели с её масштабом. Общая сумма до округления — 100 м², терраса отдельно. Округление строк может давать отклонение 0,01 м² от суммы. Это эскизные модели, не обмерный/строительный чертёж. Границы открытых зон соответствуют разбиению пола в коде.

В этом комплекте только текстовое название TOP BUILDING; утверждённый графический логотип и светлые/тёмные фасады не добавлялись, поскольку не были присланы. Страница сайта не создавалась.

Проверка: сборка пяти сцен, сопоставление геометрии исходным турам, площади, наличие локальных зависимостей, распаковка сжатого кода. PNG визуально проверены. Запуск WebGL в настоящем браузере и на телефоне не проверен.

Последняя правка: в общей ванной тура 4 умывальник и зеркало сдвинуты вправо на 0,38 единицы модели. Программно проверен непрерывный проход к унитазу. Планировка 4 PNG/SVG обновлена вместе с туром.

Обновление оформления: PNG в plans созданы генерацией изображений по референсу пользователя. Старые векторные схемы сохранены только в source/schematic-reference для сверки. Скрипт source/build_kit.py пересоздаёт старые схемы, а не художественные PNG: не запускайте его поверх финальных изображений без резервной копии. 3D-туры в этой правке не менялись.
